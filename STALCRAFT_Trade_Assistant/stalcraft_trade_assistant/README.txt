# STALCRAFT Trade Assistant — OCR prototype

## Установка
1. Установи Python 3.10 или новее.
2. Установи Tesseract OCR для Windows: https://github.com/UB-Mannheim/tesseract/wiki
3. Для стандартной установки программа автоматически проверяет путь:
   `C:\Program Files\Tesseract-OCR\tesseract.exe`.
4. Открой папку проекта в терминале и выполни:
   `py -m pip install -r requirements.txt`
5. Запусти:
   `py main.py`

## Первое использование
1. Запусти STALCRAFT: X в оконном или безрамочном режиме.
2. Запусти Trade Assistant.
3. Нажми «Выбрать область обмена». Выдели область, в которую входит подпись «Вы получите» и нижняя сетка предметов другого игрока. Верхнюю сетку лучше не включать.
4. Добавь названия предметов и цены за штуку в прайс-лист.
5. OCR периодически читает текст в выбранной области, ищет строку «Вы получите», а ниже неё сопоставляет названия из прайс-листа и количество вида x221.
6. Сумма рассчитывается как распознанное количество × цена из твоего прайс-листа.
7. «Скопировать сумму» копирует итог в буфер обмена. Подтверждать обмен и отправлять деньги программа не умеет.

## Ограничения текущей OCR-версии
- Сканер использует подпись «Вы получите» как границу, чтобы не считать верхнюю сетку.
- В первой интеграции читаются названия предметов и явное количество вида xN. Отдельные цифры/номиналы, нарисованные внутри отдельных ячеек, пока не связываются с конкретным предметом: для этого нужна проверка реального скриншота с координатами ячеек.
- Если подпись «Вы получите» или количество не распознаны, программа не пытается угадать предмет или число.
- Перед любой сделкой обязательно сверяй распознанные строки и итог вручную.

Программа только считывает изображение экрана и копирует сумму. Она не управляет обменом и не подтверждает сделки.
