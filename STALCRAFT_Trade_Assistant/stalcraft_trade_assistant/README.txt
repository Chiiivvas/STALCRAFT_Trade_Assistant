# STALCRAFT Trade Assistant — прототип

## Установка
1. Установи Python 3.10 или новее.
2. Установи Tesseract OCR для Windows: https://github.com/UB-Mannheim/tesseract/wiki
3. Добавь Tesseract в PATH (обычно `C:\Program Files\Tesseract-OCR`).
4. Открой папку проекта в терминале и выполни:
   `py -m pip install -r requirements.txt`
5. Запусти:
   `py main.py`

## Первое использование
1. Запусти игру в оконном или безрамочном режиме.
2. Запусти программу. Она остаётся поверх других окон.
3. Нажми «Выбрать область обмена» и выдели прямоугольником область, где находятся предметы другого игрока.
4. Добавь предметы в прайс-лист.
5. Для каждого предмета нажми «Добавить образец иконки», выдели иконку предмета на скриншоте и задай название и цену за штуку.
6. Программа будет периодически искать эти образцы в выбранной области, пытаться прочитать число рядом с найденной иконкой и пересчитывать сумму.
7. Нажми «Скопировать сумму», затем вставь её в игре вручную.

## Важные ограничения прототипа
- Распознавание основано на сравнении шаблонов OpenCV. Оно чувствительно к масштабу, подсветке, анимации, качеству изображения и перекрытию интерфейса.
- Количество считывается OCR из области рядом с иконкой; расположение цифр может потребовать настройки под конкретный интерфейс STALCRAFT: X.
- Для надёжного подсчёта нужно протестировать на реальных скриншотах обмена и подстроить зоны количества/порог распознавания.
- В текущем прототипе одинаковые найденные иконки суммируются по названию. Проверяй результат перед отправкой денег.
- Не запускай игру в эксклюзивном полноэкранном режиме: поверх игры виджет может не отображаться. Используй безрамочный или оконный режим.

Программа только считывает изображение экрана и копирует сумму в буфер обмена. Она не управляет обменом и не подтверждает сделки.
